# Auto Dubbing V3 Plan

日期：2026-05-03

## Summary

在现有 `subtitle-maker` 的 Auto Dubbing V2 基础上新增 `Auto Dubbing V3`，目标是把“字幕分句配音”升级为“按可见说话人分段后再配音”。

V3 首版范围收窄到“画面里有人脸”的视频场景：

- 上传视频
- 识别字幕 / 读取已有字幕
- 调用 `asd-pipeline` 的 tracked ASD 结果
- 将字幕按可见说话人归属为 `speaker_segments`
- 翻译
- 使用 OmniVoice 在字幕时间窗内做声音克隆配音
- 生成最终配音视频

## Current State

- Web 左侧栏已有 `Auto Dubbing` 与 `Auto Dubbing V2`，模板在 `src/subtitle_maker/templates/index.html`。
- 前端面板复用逻辑在 `src/subtitle_maker/static/js/dubbingPanel.js::setupDubbingPanels()`。
- Auto Dubbing 启动入口在 `src/subtitle_maker/dubbing_cli_api.py`。
- CLI 命令构造在 `src/subtitle_maker/jobs/command_builder.py`。
- 长视频配音主链路在 `tools/dub_long_video.py` 与 `src/subtitle_maker/domains/dubbing/pipeline.py`。
- OmniVoice 已接入，`TtsSynthesisRequest.target_duration_sec` 已存在，OmniVoice 后端已支持 duration 透传。

## Implementation Changes

### 1. UI / Pipeline Version

- 左侧栏新增 `Auto Dubbing V3` 菜单项与 `panel-auto-dub-v3`。
- `setupDubbingPanels()` 新增第三个实例，前缀使用 `auto-dub-v3`，`pipelineVersion = "v3"`。
- V3 首版前端保持 V2 的交互模型，只增加入口与必要文案，不首轮做复杂 speaker 审阅 UI。

### 2. API / CLI Contract

- `pipeline_version` 允许 `v3`。
- `build_auto_dubbing_command()` 在 `v3` 模式下透传：
  - `--v3-mode true`
  - `--v3-asd-api-url`
  - `--v3-speaker-segment-mode visible-face`
- V1/V2 行为保持不变。

### 3. Speaker Segment Pipeline

- 调用 `asd-pipeline` 的 `/run-tracked` 获取 `focus_predictions.json`。
- 对每条字幕时间窗统计 `focus_track_id` 覆盖，生成 `speaker_track_id`。
- 相邻同 speaker 的字幕段合并为一段话，输出 `speaker_segments.json`。
- `speaker_segments.json` 每段包含：
  - `start_sec`
  - `end_sec`
  - `speaker_track_id`
  - `source_text`
  - `translated_text`
  - `subtitle_indices`
  - `coverage_ratio`
  - `needs_review`

### 4. Dubbing Strategy

- V3 默认优先使用 OmniVoice。
- 每个 `speaker segment` 取对应说话人的参考音频片段作为 `ref_audio_path`。
- `target_duration_sec = end_sec - start_sec`。
- 继续复用当前的 duration fit、补静音、manual review、混音与成片逻辑。

## Test Plan

- `pipeline_version=v3` 的参数校验与命令拼装测试。
- speaker 归属测试：高覆盖归属 speaker、低覆盖归属 `unknown`。
- 相邻同 speaker 段合并测试。
- OmniVoice 目标时长透传测试。
- 前端测试：V3 面板提交 `pipeline_version=v3`，V1/V2 不回归。

## Assumptions

- V3 首版只做“可见说话人分段”，不做纯音频 diarization。
- `asd-pipeline` 作为外部本地服务调用，不内嵌进 `subtitle-maker`。
- 无人脸或长时间检测不到脸的字幕段允许标记 `unknown` / `needs_review`。
- 首版后端优先，先打通 `speaker_segments + OmniVoice` 闭环，再考虑 richer UI。
