2. 核心业务流程序列图

sequenceDiagram actor U as 👤 用户 participant FE as 🖥️ 前端 SPA participant API as 🌐 FastAPI participant ASR as 🧠 Qwen3-ASR participant TR as 🤖 DeepSeek participant TTS as 🔊 TTS 后端 participant FS as 💾 文件系统 rect rgb(30,40,60) Note over U,FS: 流程 A — 字幕生成与翻译 U->>FE: 拖放上传视频/音频 FE->>API: POST /upload (multipart) API->>FS: 保存 uploads/{uuid}.ext API-->>FE: { file_id, filename } U->>FE: 配置语言 / 时间范围 → 开始转写 FE->>API: POST /transcribe API->>API: BackgroundTasks 入队 API-->>FE: { task_id } API->>ASR: 加载模型, 逐 30s 块转写 loop 逐块处理 API->>FS: ffmpeg 提取音频块 ASR-->>API: 逐块返回字幕片段 end API->>FS: 写入 outputs/*.srt API->>API: status → "completed" loop 前端轮询 FE->>API: GET /status/{task_id} API-->>FE: { status, progress, subtitles } end U->>FE: 选择目标语言 → 翻译 FE->>API: POST /translate { task_id, target_lang, api_key } API->>TR: translate_batch(subtitles, target_lang) TR-->>API: 翻译后字幕 API-->>FE: 双语字幕 JSON U->>FE: 导出 FE->>API: POST /export { format, task_id } API-->>FE: SRT 文件下载 end rect rgb(40,35,30) Note over U,FS: 流程 B — 自动配音 (V1/V2) U->>FE: 配置配音参数 (语言/策略/时间范围) FE->>API: POST /dubbing/auto/start { ...params } API->>FS: 创建 outputs/dub_jobs/{batch_id}/ API->>FS: 写入 batch_manifest.json API->>API: 启动子进程 tools/dub_long_video.py API-->>FE: { task_id, batch_id } Note over API,TTS: 子进程异步执行 API->>ASR: 转写 (若无源 SRT) API->>TR: 翻译 (若无译文 SRT) API->>FS: 音频分段 (静音检测切割) loop 逐段合成 API->>FS: 提取参考人声 API->>TTS: synthesize(text, ref_audio, lang) TTS-->>API: 合成 WAV 音频段 API->>API: 时长对齐 (atempo/trim) API->>API: 响度归一 end API->>FS: 拼接全部片段 → 混音 BGM API->>FS: 合成最终配音视频 API->>API: status → "completed" loop 前端轮询 FE->>API: GET /dubbing/auto/task/{task_id} API-->>FE: { status, progress, steps, eta } end FE->>API: GET /dubbing/auto/download/{path} API-->>FE: 配音视频文件 end
