```

🌍 外部服务      DeepSeek API / Index-TTS:8010 / OmniVoice:8020
🧠 本地模型      Qwen3-ASR / ForcedAligner / Qwen3-TTS
```

**两条主数据流**

1. **字幕生成**: 上传 → ASR 转写 → DeepSeek 翻译 → 导出 SRT
2. **自动配音**: 上传 → ASR 转写 → 翻译 → 逐段 TTS 合成 → 对齐混音 → 输出配音视频

**关键设计决策**

- 配音流程通过**独立子进程**运行（`tools/dub_long_video.py`），通过 JSON manifest 文件与主进程通信
- TTS 后端采用**策略模式**（`TtsBackend` ABC），支持 Index-TTS 和 OmniVoice 两种实现
- 任务状态用**轮询**（非 WebSocket），前端定时查询 `/status/` 和 `/dubbing/auto/task/`
- 用户配置（API Key、主题、TTS 选择）存于浏览器 **localStorage**
